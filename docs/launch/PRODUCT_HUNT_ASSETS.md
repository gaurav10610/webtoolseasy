## Short description

WebToolsEasy combines two workflows developers hit daily: understanding pasted technical data and estimating cloud costs. DevLens auto-detects JWT/JSON/regex/certs and explains them instantly. ArchCost lets you drag AWS services, model transfer costs, compare options, and export PNG/PDF/CSV.

## Long description

WebToolsEasy is a privacy-first developer studio built for debugging and planning.

DevLens turns a paste into answers. Paste JWT, JSON, regex, Base64, timestamps, env files, certs, CSV, and more, then inspect with specialist views and structured explanations.

ArchCost is a visual AWS architecture cost planner. Drag services onto canvas, configure pricing options (on-demand/reserved/spot), account for data transfer, compare two architecture options side by side, and export polished reports.

Everything runs locally in your browser by default. No account required.
