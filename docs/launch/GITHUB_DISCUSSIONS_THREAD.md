Title: Request New Data Types and AWS Services for WebToolsEasy

Thanks for trying WebToolsEasy.

Use this thread to request:

- New DevLens input/data types (for example protobuf, HAR, OpenAPI, Terraform plan)

1. What input/service you need
2. Your real debugging/planning use case
3. Expected output or analysis you want

This helps prioritize additions that solve real engineering workflows.
