# Workflow Domain Glossary (TB-001)

- Pack: a reusable workflow definition that groups sequential steps for one repeatable job.
- Step: one executable unit in a pack, labeled by execution mode (local-only, network, export-only).
- Run: one execution instance of a pack with step progress, status, and timestamps.
- Artifact: an output generated by a step, including type, checksum, size, and source step.
- Preset: a saved configuration shortcut for quickly rerunning a pack.
- Recipe: a shareable serialized preset payload with integrity validation.
