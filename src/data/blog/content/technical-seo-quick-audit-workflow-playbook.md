# Technical SEO Quick Audit Workflow Playbook

Use this playbook when you need a fast, repeatable SEO check before publishing.

## Workflow Steps

1. Verify robots and sitemap discoverability.
2. Validate title, description, and canonical basics.
3. Check structured data readiness.
4. Export action-ready audit summary.

## Why This Workflow Repeats Well

- Gives teams a predictable pre-launch SEO checkpoint.
- Produces the same report shape each run for easier triage.
- Keeps URL and metadata checks focused and lightweight.

## Suggested Preset

- Preset name: `SEO Quick Audit Starter`
- Run pre-publish in every release cycle
- Share exported report in launch checklist
